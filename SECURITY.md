# Security Policy

## Supported Versions

Only the latest release built from this fork (`https://github.com/MangTianYa/MaterialFiles`) is supported with updates.

## Reporting a Vulnerability

- For issues introduced in or specific to this fork (`MangTianYa/MaterialFiles`), please open an issue at https://github.com/MangTianYa/MaterialFiles/issues rather than contacting the upstream author.
- For vulnerabilities present in the original upstream codebase (`zhanghai/MaterialFiles`), upstream contact details remain `dreaming.in.code.zh@gmail.com`.
